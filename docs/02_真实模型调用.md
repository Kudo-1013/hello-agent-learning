# 第二课：接入真实模型

本节沿用 Yuan-Meeting 示例配置中的通义千问 OpenAI 兼容接口。只验证一次真实对话，暂不加入工具。

1. 打开项目根目录的 `.env`。
2. 只在 `LLM_API_KEY=` 后填写自己的 DashScope API Key，不加引号，不要把 Key 发到聊天中。
3. 保留已有的服务地址和模型名。
4. 运行：

```powershell
.\.venv\Scripts\python.exe .\examples\02_real_model.py
```

成功时会输出 96 或含义相同的简短回答。这证明程序已调用真实模型，但还不算 Agent 工具闭环。

需要看懂的主线：读取环境变量 → 创建客户端 → 发送 messages → 从 response 中取出模型文本。
