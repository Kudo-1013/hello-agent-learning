# 第三课：模型选择工具

运行 examples/03_model_selects_tool.py。该文件把工具说明交给真实模型，只打印模型返回的 `tool_calls`，暂时不执行 `multiply()`。

需要区分：

- `multiply` 是本地 Python 函数。
- `tools` 是提供给模型看的函数说明，不会执行函数。
- `message.tool_calls` 是模型提出的调用请求，包含工具名和 JSON 参数。
- 下一步才由 Python 解析参数并执行本地函数。

运行：

```powershell
.\.venv\Scripts\python.exe .\examples\03_model_selects_tool.py
```

不要把 `.env` 或 API Key 的内容发到聊天中，只发送终端里的模型文本和工具调用请求。
