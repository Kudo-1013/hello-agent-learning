# 第一课：谁在调用工具？
对应官方第 1 章 1.2.2 与 1.3。
本地示例是单独编写的教学简化，用固定响应模拟模型，没有网络或真实 AI 决策。

输入：帮我计算 137 加 286。
第一轮模拟模型给出 add 和参数 → Python 执行得到 423 → 把结果写入消息 → 第二轮模拟模型给出最终回答。

先运行 examples/01_loop_demo.py，再回答：
1. 哪一行真正执行 add？
2. 不把工具结果写入 messages 会怎样？
3. max_steps 为什么存在？

mock_model 的规则仅用于演示，下一阶段替换成真实 API。
本例消息格式是教学用内部字典，不应直接当作模型供应商 API 的请求格式。
